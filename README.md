# Portafolio de Arquitectura

Prototipo de portafolio web profesional diseñado para despachos de arquitectura. Desarrollado con HTML5, CSS3, JavaScript Vanilla y GSAP para animaciones fluidas.

## Estructura de Archivos
* `/index.html` - Página principal
* `/css/styles.css` - Sistema de diseño y paleta
* `/js/main.js` - Controladores de animación GSAP
* `/proyectos/` - Carpeta para páginas individuales de proyectos

## Cómo publicar en GitHub Pages
1. Crea un nuevo repositorio en GitHub llamado `portafolio-arquitectura`.
2. Extrae los archivos de este ZIP y súbelos a tu repositorio (directamente en la raíz).
3. Ve a **Settings** (Configuración) en tu repositorio.
4. En el menú lateral izquierdo, haz clic en **Pages**.
5. En la sección "Build and deployment", bajo "Source", selecciona **Deploy from a branch**.
6. En "Branch", selecciona `main` (o `master`) y la carpeta `/ (root)`, luego haz clic en **Save**.
7. En un par de minutos, tu sitio estará en vivo en: `https://[TU_USUARIO].github.io/portafolio-arquitectura/`

## Personalización
Para cambiar imágenes, reemplaza las URLs en las etiquetas `<img>` dentro de los archivos HTML por fotografías reales, o guarda las imágenes locales en una carpeta `/assets/images/` y actualiza las rutas.
